# ゴジュンワールド

英語の語順を「文の要素の箱」で身につけるステージ制ゲーム。

## ファイル

| パス | 中身 |
|---|---|
| `data/world1.csv` など | 問題データ（1ワールド1ファイル） |
| `src/gojun-src.html` | ゲーム本体（`@@CSV@@` の所に問題データが入る） |
| `build.js` | データを合体・チェックして `gojun-world.html` を作る |
| `gojun-world.html` | 公開用の完成ファイル |
| `preview/` | 手元確認用（`node preview/serve.js` → http://localhost:5178） |

## 公開（Cloudflare Workers）

- 設定は `wrangler.jsonc`：`preview/` の中身をそのまま公開する（英語版が `/`、ドイツ語版が `/de`）。`preview/serve.js` は手元確認用なので `preview/.assetsignore` で外している
- Cloudflare の画面では、ビルドコマンド `node build.js && node build.js de`、デプロイコマンド `npx wrangler deploy`。Worker の名前は `wrangler.jsonc` の `name`（いまは ord）とそろえる
- 直したら `node build.js` と `node build.js de` を実行してからコミット・プッシュ（`preview/` の中身もコミットしてある）

## 問題を足す・直す

1. `data/` の CSV を Excel などで編集（新しいワールドは `world3.csv` のように追加）
2. `node build.js` を実行。日本文に含まれない文節、列の数のずれ、ページが読みこめないデータがあるとエラーで教えてくれる
3. ブラウザで開いてコンソールに `gojunSelfTest()` と打つと、全問の模範解答と語順の別解が正解になるかをまとめて確かめられる

### 1歩に1つだけ新しいこと（文を作るときのきまり）

- **新しい単語は LV0〜LV2 で出す**。打ちこみのステージ（LV3・LV4）で初めて出る単語は4つまで、ボスは2つまで（ボスは「覚えたものを使う」場所）。超えると `node build.js` が「注意：打ちこみ・ボスのステージに新しい単語が多い」と、ステージと単語を出す（止まりはしない）。直し方は、前のステージに出た単語に言いかえるか、その単語を LV0〜LV2 の文で先に出す。語形のちがい（study / studied、komme / kommt）と人名・地名、I・the などの小さな語は数えない
- **段差をつくらない**：LV0・LV1 の模範解答は短い言い方を先に書く（a lot of より many、in front of より near など。`||` の最初が模範解答とカードになる）。LV4（箱なし）は1文目だけ箱ヒントが自動で出て、2文目から箱なし
- **ステージの1文目はやさしい文に**。ただし、キャラのセリフへの返事になっている文や、話の始まりの文はそのまま（文を長さで自動で並べかえると、会話や話の順番がこわれるため、自動にはしていない）

## CSV の列

| 列 | 内容 |
|---|---|
| world, stage | ワールド番号・ステージ番号 |
| level | L0 / L1 / L2 / L3 / L4 / BOSS |
| title | ステージ名 |
| type | INTRO（場面説明）/ GOAL（めあて）/ TALK（相手のセリフ）/ Q（問題） |
| speaker | TALK の話し手 |
| ja / en | 日本語の文 ／ TALK の英語 |
| chunks | `S:私は=I / V:です=am / C:ケン=Ken`（英語の語順で書く） |
| distractors | LV2 のひっかけカード（`|` 区切り） |
| note | 正解後に出す「ポイント」（空なら文の形から自動で説明を作る：be動詞・3単現・過去形・O が2つ・後置修飾・比較・受け身など。`autoNote`） |

GOAL 行（1ステージに1行・任意）：ja に「めあて」（「〜できるようになろう」「〜を身に付けよう」の形で書く）、chunks に箱で見せる例文、note に「できるようになること」を書く。
ステージ開始画面には「めあて」と例文だけを出す（情報を減らすため）。「できるようになること」はクリアしたときに結果画面で「できるようになった！」として出し、マップのステージ画面にもクリア後だけ「できるようになった ✓」と出る。新しい箱は開始画面に名前と問いかけ（例：S だれが・なにが）だけを小さく出し、意味は遊びながらつかませる（くわしくは ？ ボタン）。

RULE 行（任意・1ワールドにいくつでも）：マップの「がっこう」で順に学ぶルール。stage に「練習するステージ番号」、ja にルール、chunks に例文、note に説明（`\n` で改行）。
たしかめ問題を自分で決めるときは、title に日本語、en に正しい文、distractors にまちがい文を書く（書かなければ、そのステージの問題から「日本語の順のままの文」をまちがいとして自動で作る）。
RULE 行がないワールドは、各ステージの GOAL（めあて）をルールとして使う。英語版・ドイツ語版とも、いまは全ワールドに RULE 行がある（めあては目標、RULE はルールの説明として書き分ける）。

TABLE 行（任意）：すぐ上の RULE 行につく「形の小さな表」（例：sein の形 ich bin / du bist / er ist / wir sind）。ja に表の名前、chunks に表（行は `;`、マスは `|` で区切り、1行目は見出し）。そのワールドで覚える形だけを書く（全部の一覧は作らない）。
- 学校ではそのルールの中に出る。学校のもくじ・まとめと「？」ボタンの「このワールドで覚える形」で、そのワールドの表だけを1ページで見られる（`openTables`）
- マスの中の `[bin]` は「形」。問題の答えから自動で探して、練習ずみなら ✓、まだならそれを練習するステージ番号を出す
- 同じつづりで意味がちがう形は `[der=der Trainer/der Bahnhof]` のように、数える言い方を指定する（表示は der）

学校の各ルールには「出てくる単語」が自動でつく（ドイツ語版のみ）。説明・表・たしかめ問題に出てくる単語の意味を、問題データ（1語の答え → その日本語の文節）から引く。例文の箱や表ですでにわかる語は出さない。der・ein・sein の形など、意味が1つに決まらない小さな語は `GLOSS_FIX` で決めている。ドイツ語版ワールド1の最初のルールは「まず覚える「だれが」の言葉」（ich・du・er・sie・es・wir）。

chunks の書き方：

- 文節の日本語（`=` の左）は日本文の一部をそのまま書く
- 別解は `||`：`C:14歳=fourteen||14`
- 文頭にも置ける M は `M~`：`M~:毎日=every day`
- LV1 で動詞の形を選ばせる：`is{be}`（am/is/are）、`likes{like|likes}`、`went{go|goes|went}`
- 日本語にない語（天気の It など）は `=` の左を空にする：`S:=It`。LV2 では主語さがしを飛ばし、「日本語に主語がない」ことを説明する
- There is 構文は `V:あります=There is` を先頭に書く。ことわりの説明は自動で出る
- 箱の種類は S・V・O・C・M に加えて、N（かたまりの中心の名詞）、J（接続詞 that / because / when / if）、A（疑問文で前に出る助動詞 Do・Can など）、W（疑問詞 What・Where など）
  - 疑問文：`A:=Do / S:あなたは=you / V:好きですか=like / O:納豆が=natto`（Do は日本語にないので `=` の左を空に）
  - 後置修飾：`S:机の上の本は=[N:本=The book / M:机の上の=on the desk]`（M に「↩ 前の名詞を説明」が付く）
  - 文の中の文：`O:英語はおもしろいと=[J:と=that||- / S:英語は=English / V:=is / C:おもしろい=interesting]`
  - because / when / if のかたまり（J を含む M）は、文の最初に置いても正解になる
- 書かなくてもよい語は答えに `-` を入れる（`that||-`）。LV4 の自由入力で省略を正解にする（箱の中では書く必要がある）
- 入れ子の箱（かたまり）は `[ ]`：`O:サッカーをすることが=[V:すること=playing / O:サッカーを=soccer]`
  - かたまりの日本語（`=` の左）の中に、中の箱の日本語がそのまま入っていること
  - かたまりの中にかたまりは入れられない。かたまりに `~` はつけられない

## 箱のせつめい

S・V・O・C・M とかたまりの説明は `ROLES`（`src/gojun-src.html`）にある。
ステージに初めて出てくる箱は開始画面に「NEW」として出て、いつでも「？」ボタンで見られる。

## チュートリアル

はじめての操作のときに、ハコまるが画面の一部を照らして案内する（`TUTORIALS`）。
「やってみよう！」の手順は、生徒が実際に操作するまで次に進まない。説明だけの手順は、生徒が画面を操作し始めたら自動で次の「やってみよう！」まで進む。正解したら自動で閉じる（結果の説明だけ3.5秒見せる）。チュートリアル中はタイマーが止まる。
出るタイミング：マップ初回、各レベル（LV0〜LV4・ボス）の最初の問題、手練モード初回、かたまり・後置修飾・破線の箱の初登場。
設定で「チュートリアル」のオン・オフと、「もう一度」（全部リセット）ができる。
「？」ボタンの「この画面のチュートリアルを見る」で、今いる画面に合うチュートリアルをいつでも再生できる（見たことがあっても、オフにしていても出る）。

## あそびの要素

- 効果音（ブラウザで合成。設定でオフにできる）
- 1回目で正解が続くと「〇れんぞく！」。結果画面に最大コンボ
- ★3つ（またはタイムアタック金メダル）で紙ふぶき
- タイムアタック：クリア済みステージで選べる。説明・チュートリアルなしですぐ始まり、ミス1回につき＋5秒。
  目標タイムの 50% 以内で金、75% 以内で銀、100% 以内で銅。記録はふつうの星とは別に残る

## 単語道場

- 単語の予習はステージから切りはなして、寄り道の「単語道場」にした（ステージ開始時の「予習する？」はなくした）
- マップの道のとちゅう、各ステージの手前に「カードせんせい」が立つ（`dojoStops`）。そのステージで**初めて出る**単語（最大10）がない所と、まだ行けないステージの前には立たない
- 次に遊ぶステージ（選んでいるステージ）の手前のせんせいだけが「予習しようよ！」と話す。打ちこみのステージ（LV3・LV4・ボス）の前では「打つ前に予習しよう！」。全部「知ってる」になると ✓ がついてうすくなる
- タップすると単語道場（`openDojo`）：**フラッシュ**（カードをめくって意味を覚える）か **徹底**（見て聞く → ならべかえ → 穴うめ → ぜんぶ打つ）を選ぶ。ステージ画面の「単語道場」ボタンからも開ける
- プレイ中に同じ単語を2回打ちまちがえると、結果画面で「単語道場で練習しよう」とすすめ、その単語だけで道場を開ける（単語は「学習中」に入る）
- ステージで使う英語の「かたまり」（例：私の好きなスポーツ ↔ my favorite sport）をフラッシュカードで覚えられる
- カードは問題データから自動で作る（I・is・the などの簡単な語 `VOCAB_SKIP` と、人名・地名だけのカードは除く。in Osaka のように前置詞と組みのものは残す）
- 「知ってる」にしたカードは、ほかのステージでも出ない。「知らない」は最後にもう一度回せる
- 徹底的に覚える（`openDrill`）：見て聞く → 文字のならべかえ → 穴うめ（半分の文字が＿）→ ぜんぶ打つ（文字数だけ）の4段階。ならべかえはキーボードでも打てる（文字のボタンは文字のキー、単語のボタンは頭文字のキー）。穴うめは、上に ＿ 入りの単語を見せ、下に**単語をぜんぶ打ちなおす**（打った文字は緑になり、上の ＿ も通りすぎると文字が出る）。文字は下の文字ボタン（単語の文字＋形や音の似たまぎらわしい文字、10こ以上）から選ぶ。まちがい2回までなら次の段階へ。キーボードで打ってもよく、ä・ö・ü・ß は a・o・u・s のキーでもOK（`drillLetterTiles`・`fillMatch`）。ドイツ語版の「ぜんぶ打つ」には ä・ö・ü・ß を入れるボタンがつく。単語は交代で出て（すぐ連続しない）、打ちまちがえると1段階もどる。ならべかえは、まちがいタップ2回以上でもう一度。全部終わると「知ってる」に入る。仕分けのあと「知らない n枚を徹底的に覚える」、単語一覧の「徹底的に覚える」から始められる


### カードに出す意味

- ふだんは、例文の日本語のうちその単語にあたる部分を出す。「〜は・〜が・〜を」は取る。場所や時のかたまり（M）は「に・で・へ」も意味のうちなので残す（in Osaka ＝ 大阪に）。動詞の疑問の「か」は取る
- 例文から切り出すと意味にならない語（möchte＝「たいです」、kann＝「せます」、sehen＝「見」、文の最後に離れる auf・an など）は、意味の表 `data-de/gloss.txt`（英語は `data/gloss.txt`）に「単語 = 意味」で書く。「-」と書くとカードにしない
- 学校のルールの単語の意味も同じ表を使う。sein は「＝（〜は…です）」。プレイ画面の箱でも、英語版の be 動詞（am・is・are・was・were）とドイツ語版の sein の V の箱を「＝」と出す（私は｜＝｜ケン。「です・だ」→「＝」、疑問「ですか」→「＝？」、過去「でした・だった」→「＝だった」。`seinBox`）。ドイツ語版の現在完了（Ich bin … aufgestanden／Ich habe … gespielt）で、日本語のない haben・sein の箱は「過去のしるし」と出す。同じ節に過去分詞（ge…t／ge…en）があるときだけで、dass・weil などの節の最後の ist や、英語の that 節の is のように、日本語の単語がない be・sein の箱は「＝」（過去は「＝だった」）と出し、その節の主語の「は」も出さない（〜ということ｜ドイツ語｜おもしろい｜＝）。つなぎ言葉（J）の箱は働きがわかる言い方にする：と→〜ということ、ので→〜ので、とき→〜とき、もし→もし〜なら、けれど→〜けれど、かどうか→〜かどうか、前に→〜する前に（英語版・ドイツ語版とも。日本語の文はそのまま）。「＝」の箱がある文では、同じ節の S の箱の「は・が」も出さない（私｜＝｜ケン）。V の箱の見出しも「する・＝」。「います・あります」のように「いる・ある」の意味のときはそのまま。日本文の中の位置さがし（見つける・仕分け）は元の「です」で行う（`jaSrc`）。「見つける」では、＝の文の日本語を「私たちの学校｜は｜大きい｜です」と区切り、「は」と「です」を組で V（＝）にする。どちらをタップしても V が見つかったことになり、文の表示が「私の両親は親切です。」→「私の両親 ＝ 親切。」に切りかわる（「は」が「＝」に変わり、「です」は消える）。まちがえたときのヒントも「「は」の前の部分が主語」「「は」と「です」が組で「＝」」と出す。主語と中身を「＝」でつなぐ動詞として説明する（「です」1語とは対応させない）。bin・ist などは「＝（〜は…です・ich）」のように主語を添える
- ブラウザのコンソールで `gojunCards()` を実行すると、全カードの意味を一覧で確かめられる
## とことんドリル

クリアしたステージの「とことんドリル」ボタンから。そのステージと同じ文の形で、単語を入れかえた文を10問ずつ、何回でも（「もう10問」）。ならべかえ（LV1、動詞は形を選ぶカード）か打ちこみ（LV3）を選ぶ。星・場面カード・にがてリストには入らない。最初の回だけ、新しい単語を単語カードで確認できる。

ドリルのないステージ・まだクリアしていないステージでも、ボタンはグレーで出る（「準備中」「クリアで解放」）。タイムアタックも同じ。

DRILL 行（1ステージ1行・任意）：chunks に JSON で文の形を書く。英語版は `data/make-drills.js`（`node data/make-drills.js` で `data/zz-drills.csv` を作る）、ドイツ語版は `data-de/make-csv.js` の `DRILLS`。どちらも全ステージにある（英語78・ドイツ語24）。
- 文法ごとの文の形：英語は40ステージ、ドイツ語は14ステージ
- まとめ・ボスのステージ（L3・L4・BOSS など）は `{ "use": ["1-1", "1-2"] }` で、そのワールドの文の形をまぜて出す（1問ずつ交代）
- 時の言葉で形を変える：`M` の単語に `"g": "past"` / `"g": "now"` をつけ、動詞の `f` に `past` を足す（`{ past: 'played', '3s': 'plays', … }`）。`ja` は `{ past: 'しました', _: 'します' }`（`_` はそれ以外のとき）
- `ja`：日本文に並べる順（`"M、"` のように書くと後ろに「、」）、`en`：答えの順（`"M~"` は文頭にも置ける）、`q`：疑問文、`opt`：ときどき省く箱、`note`：毎回出すポイント
- `slots`：箱ごとの単語リスト。キーの1文字目が箱（S・V・O・C・M、2つ目は V2・M2）。単語は `[日本語, 答え, 人称]` か `{ ja, en, f: { "1s": 形, … }, o: 種類 }`
- 主語の人称（1s・2s・3s・1p・3p）で動詞の形 `f` を選ぶ。動詞などの `o`（種類）で、`{ 種類: [単語…] }` の形のリストから合う単語を選ぶ（「パンを飲む」にならない）。`o` は `['person', 'friend']` のように複数書ける
- かたまり（入れ子の箱）は `{ in: { ja, en, slots } }`。中も同じ書き方で、中の主語で中の動詞の形が決まる（that cats are / dass … ist）。中で決まった種類は外にも伝わる（「男の子」→ C は my brother など）
- `g`（形の札）：want は `"g": "to"`、like は `"g": "ing"` のようにつけると、あとの単語の `ja`・`f` を `{ "to": …, "ing": … }` で書き分けられる（to play／playing、し／することが）
- なるべく使われていない単語から選ぶので、リストの単語がまんべんなく出る（`drillOne`）
- 自己テスト（`gojunSelfTest()`）で、各ドリルから60文ずつ作って、答えの順・日本文・箱を確かめる

## ルールの学校

マップの道のそばの「がっこう」（ステージ画面の「ルールの学校」ボタンも同じ）。もくじ → ルール1つずつ（例文の箱・説明・練習するステージへのリンク・たしかめ問題）→ まとめ。たしかめに答えるまで次へ進めない。見終わると建物に ✓ がつく（`openSchool`）。
置き場所は、島の上で道・ステージ・飾りと重ならない、ステージ1・2に近い所を自動で探す（`placeSchool`）。
- 表は日本語・裏は英語（読み上げあり）。英→日にも切りかえられる
- カードの下の「英語を聞く」でいつでも発音が聞ける。英→日のときは、カードが出たときに自動で読み上げる
- ステージ前の予習に出るのは「このステージで初めて出る英語」「学習中の英語」「まだクリアしていないステージの英語」だけで、最大8枚（`preDeck`）
- 開始画面と設定でオン・オフ。途中で「スキップしてスタート」できる。タイムアタックでは出ない

- プレイ中の「単語」ボタン、マップの「単語カード」ボタンで、いつでもステージの単語一覧とカード練習を開ける（ふつうのステージでは時間が止まる。ボス・タイムアタックでは止まらない）

## こまったとき

- 1つの文で3回まちがえると「こたえを見る」が出る（並べかえ・主語さがし・打ちこみ・自由入力のどれでも）。お手本とポイントを見て次へ進める。その文は「にがて」に入り、そのステージでは時間の★と手練の王冠はつかない
- イギリスつづり（favourite・colour・centre など）も正解にする（`UK_US`）

## ボス戦

- ハードモード：ワールドのボスをクリアすると、そのワールドの全ステージ（ボス以外）をボスと同じルールで遊べる（文字数ヒントだけ・♥つき・説明なしですぐ始まる）。記録はふつうの星とは別（ステージ画面の「ハード ベスト」、マップの赤い H）。ボスを初めてクリアした結果画面で解放を知らせる

- 飛び級チャレンジ：ワールドに入れれば、ボスはいつでも挑戦できる。ボスに勝つと、そのワールドのステージが全部ひらく

- ♥3つ（4分の1ずつ・合計12）が制限時間に合わせて減る。まちがえるたびにも4分の1減る。0になったらゲームオーバー
- 3つ目の★は「♥を半分以上のこす」
- 打ちこむ箱の下に、打った文字数が ●○ で出る（LV3 は頭文字も出る）

## きろくと復習

- まちがえた文は「にがて」に入り、1日後 → 3日後 → 7日後に「今日の復習」として出る。ノーミスで3回正解すると卒業、まちがえると最初から
- 「きろく」ボタンに今日の復習の数がバッジで出る。復習は「きろく」画面から
- ミックス復習：クリアしたステージが5つ以上になると、マップと「きろく」から選べる。いろいろなワールドの文を5文まぜて LV3 の打ちこみで出す（`makeMix`）。星や場面カードは変わらないが、まちがえた文は「にがて」に入る
- 「きろく」画面：学習の数字だけ（★・場面カード・といた文の数・1回で正解した割合・続けたきろく・まちがえやすいポイント・復習・ワールドごとの進み具合）。集めるものは「コレクション」へのボタンから

## コレクション

- 集めるものは、本のボタンから開く「コレクション」1ページにまとめた（`renderBook`）。上に称号と★、その下に種類ごとのタブ（数と進みぐあいのバー）
- タブ：場面カード／レアシール／ハコまるの衣装（タップで着がえ・まだの衣装は「W1 あと★n」）／マップのしかけ（ごほうびと次まであと何こ・ひみつのステージ）／TAメダル（タイムアタック解放後。ステージごとの金・銀・銅）
- 新しく増えたものがあると、本のボタンとそのタブに「!」が出る。タブを開くと消える（`save.colSeen`）
- 画面の上の★（称号）を押してもコレクションが開く
- 「まちがえやすいポイント」：誤答のヒント文から文法事項（語順・be動詞・3単現・過去形など）を判定して数え、上位3つにコツと練習先のワールドを出す（`CATS`・`catOf`）
- 結果画面のボタン（もう一度・マップへ・つぎのステージ）は星のすぐ下
- 記録はその端末のブラウザにだけ保存される

## 画面の上のメニューとスマホのマップ

- はばが 880px 以上（PC）：ロゴ・★と称号・今日のミッション・初心者/手練・きろく・コレクション・?・設定を1行に並べる
- それより狭いとき：ロゴ・★・今日のミッションだけを出し、ほかは右はしの「≡」メニューにまとめる（`#topmenu`）。きろくの復習バッジやコレクションの「!」があると、「≡」にも「!」が出る。560px 以下では、ロゴの小さい文字と★の「/ 252」・称号を省く。地図の上のワールドの横並びは隠し、かわりに「WORLD 1　はじめまして島 ▾」の名前をタップすると、ワールドを縦に並べたリールが開く（`reelOpen`）。まん中の帯にあるワールドが大きく見え、離れるほど小さく薄くなる。タップでそのワールドへ。まだ行けないワールドは薄く、解放の条件だけ出る。外をタップ・Esc で閉じる。↑↓キーでも動かせる
- マップの下にあった箱の色の説明（凡例）はなくした。「?」ボタンで同じ説明が見られる
- はばが 560px 以下のときは、マップは横長のまま横にスクロールする
- チュートリアルや「NEW！」のお知らせが指すものへ、確実に画面を動かす
  - マップの中のもの（がっこう・ステージ・単語道場）は、まずマップを横に動かして真ん中に出す（`coachPan`）
  - 「≡」メニューの中のもの（手練・?・きろく）は、メニューを開いてから指す。案内が終わるとメニューは閉じる
  - そのあとページを縦にスクロールして、光る枠と説明を画面に入れる。スクロールが途中で止まって光る枠が画面の外に残ったら、1秒以内にそこへ移る（`coachScroll`）

## マップのしかけ（イースターエッグ）

- マップの飾り（丘・木・羊・船・灯台・観覧車・火山など30種類）をタップすると動いて、英語の擬音語（Baa! / Toot toot! / Ding-dong! など）が出る（`TOYS`）
- ハコまるをタップすると跳ねてひとこと話す。素早く5回タップすると「ひみつのダンス」
- 初めて触ったしかけは「はっけん n/32」と数え、コレクションに出る
- ごほうび（`REWARDS`）：8こでぼうし、16こでちょうネクタイ、24こでサングラス、32こ全部で金色のハコまる＋王冠・認定画面・ひみつのステージ「ハコまるの早口ことば」（`SECRET_STAGE`）。着せかえはマップと会話のアイコンに出る

## WORLD 0「はこの島」と、機能の解放

はじめての人は WORLD 0（5ステージ・とても簡単な文）から始まる。操作を1つずつ覚える島で、0-5（ボス）をクリアするとワールド1が開く。島の上の「もう知ってる」ボタンで飛ばせる（`skipTutorial`）。問題は `data/world0.csv`・`data-de/world0.csv`。

| ステージ | 覚えること |
|---|---|
| 0-1 はじめての箱 | S・V の箱にカードを入れる（LV0） |
| 0-2 ならべてみよう | O の箱、ならべかえ（LV1） |
| 0-3 学校へ行こう | S と V をさがす（LV2） |
| 0-4 打ってみよう | 頭文字ヒントで打ちこむ（LV3） |
| 0-5 箱の名前をおぼえよう | 日本語だけで S・V・O・C・M に仕分ける（仕分け） |
| 0-6 はこの島のボス | ♥と制限時間 |

**仕分け（level `SORT`）**：英語・ドイツ語は打たない。日本語の文のかたまりが文の順に1つずつ光り、S（主語・だれが）／V（動詞・する・です）／O（目的語・なにを）／C（補語・＝だれ・なに・どんな）／M（修飾語・いつ・どこ）のボタンで仕分ける（`renderSort`・`sortTap`）。C は「S＝◯◯ と言えたら C」のイコールテストで見分ける。C でまちがえると「『私＝ケン』と言えるかな？」、O などに C を選ぶと「『私＝パン』とは言えないね」と、その文の言葉で返す。C の箱には「＝」マークがつく。1回目のまちがいは「だれが？する？…と聞いてみよう」、2回目はその箱の見分け方をヒントに出す。全部仕分けると「英語では S → V → O の順にならべると：…」と英文を見せて読み上げる。CSV の書き方はふつうの Q 行と同じ（level を SORT に）。単語道場・にがて復習・学校の自動たしかめには使わない。学校には「箱の名前と見分け方」の表がつく。

機能はステージをクリアするたびに1つずつ開く（`FEATURES`）。開いたときは結果画面の上にポップアップ（`featPopup`：開いた鍵のアニメーション・効果音・紙ふぶき、機能の説明と「どこにある？」）が出て、結果画面にも「NEW！」が残る。マップに戻るとハコまるがそのボタンを指さして説明する。まだ開いていない機能は隠し、**次に開くものだけ**グレーで「〇〇をクリアで解放」と出す。

| 開くタイミング | 機能 |
|---|---|
| 最初から | はじめる・？（箱のせつめい）・設定 |
| 0-1 クリア | 単語道場（道のカードせんせい・単語道場ボタン） |
| 0-2 クリア | ルールの学校（マップの「がっこう」） |
| 0-3 クリア | ★と称号・きろく・コレクション |
| 1-2 クリア | とことんドリル |
| 1-3 クリア | タイムアタック |
| まちがえた文が出たら | にがて復習 |
| ステージを5つクリア（WORLD 0 は数えない） | ミックス復習 |
| ワールド1のボスをクリア | 手練モード・ハードモード |

- WORLD 0 ができる前から遊んでいた人（ワールド1以降に記録がある人）は、全部開いた状態でワールド1から始まる
- 設定の「全部解放（先生用）」でも全部開く。「進み具合をリセット」すると、機能もまた1つずつ開く状態にもどる
- 自分の CSV に WORLD 0 がないときは、WORLD 0 で開く機能は最初から開いている

## 1問のテンポと「できる度」

- **レベルのアイコン**：見る＝目、ならべる＝手、見つける＝虫眼鏡、打つ＝キーボード、箱なし＝えんぴつ、仕分け＝箱、ボス＝王冠（`LEVELS` の badge）

- **置いた瞬間に判定**（LV0〜LV2・初心者モード）：カードは正しい箱ならカチッとはまり（緑）、ちがえばはね返って理由が出る（まちがい1回に数える）。全部はまると自動でこたえあわせ。「こたえあわせ」ボタンは手練モードだけ

- **2回目からは開始画面なし**：クリアしたことのあるステージは、はじめる・もう一度ですぐ始まる

- **ウォームアップ**：LV0〜LV4 のステージは、前にクリアしたステージの文を1問「ウォームアップ」として最初に出す（`warmUp`）。まちがえても★（ノーミス）には響かない

- **できる度**（`save.mast`、0〜100%）：ステージの型ごとに、1回で正解すると +20、その文の最初のまちがいで −10。ステージ・にがて復習・ミックス・ウォームアップすべてで動く。マップの各ステージの★の下に小さなゲージだけを出す（ボス・仕分け・まだ開いていないステージには出さない）。ステージにマウスを乗せると、ステージのカード（ポップアップ）が出る（`nodeTip`）。クリック・タップするとカードが開いたままになり、外をタップするか Esc で閉じる。カードの中身は上から「番号と問題の形式のバッジ（小さく）」「タイトル」「めあて」「できる度のメーター（ボス・仕分けにはない）」「はじめるボタンと、とことんドリル（くり返しの矢印）・タイムアタック（ストップウォッチ）のアイコンボタン（クリア後）」。まだ開いていないステージはボタンのかわりに「前のステージをクリアすると開くよ」。マップの下のステージ説明とボタンもそのまま使える。学校のルール一覧にもメーターで出る

## 続けるしかけ（やる気の設計）

- **今日のミッション**（`MISSIONS`・`ensureDaily`）：1日3つの小さな課題。いま使える機能から選ぶ（例：ステージを1つクリア／にがて復習を1回 または ミックス復習 または ステージを2つ／単語道場で1回 または ノーミスで1つ）。画面上の「今日 n/3」から見られる。3つ全部でその日のスタンプ（ポップアップ）。まだのミッションはボタンになっていて、押すとそこへ行ける：ステージのクリア・ノーミスは「いちばん進んでいるステージ」（クリアした中でいちばん先のステージの次。`frontStage`）をマップで選んでカードを開く（`goStage`）。単語道場はそのステージの単語道場、にがて復習は復習を始める（今日の分がなければ「きろく」）、ミックス復習はミックスを始める。「つづきから」も同じいちばん先のステージから始まる。
- **おかえり画面**：1日1回、記録がある人にはハコまるが「前回は n文 といたね」「復習が n文 あるよ」と声をかけ、ミッションと「つづきから」（次に遊ぶステージへ1タップ、`nextStage`）を出す。
- **週の目標**：今週 3日 あそぶ（1日1つでも何かすればOK）とポップアップ。毎日の連続記録は使わない（途切れたときにやる気をなくすため）。月〜日の7マス（● あそんだ日・★ ミッション全部の日）。
- **ゴールまでの距離**：上の ★ に次の称号までのバー。ステージ中は「あと n文」。
- **負けたとき**：「あと n文 でクリアだったよ」と進んだ所まで見せる。同じステージで2回負けると「♥を1つふやして再挑戦」（時間が 4/3 倍・♥4つ。★の「♥を半分以上」はもらえない）。打ちまちがえた単語があれば単語道場へ。
- **せいちょう**：結果画面に「ベストより n秒 はやい」「1回で正解 a文 → b文」（自分の前回とだけ比べる）。
- **ハコまるがおぼえている**：前にまちがえた文を1回で正解すると「前にまちがえた『…』、きょうは1回でできたね！」。
- **レアシール**：ステージクリアで ときどき（12%）ことばのシール（英語 Great! など・ドイツ語 Toll! など、12種）。「コレクション」のレアシールに集まる。
- きろくに「今週といた文・今週あそんだ日・スタンプ・週の目標」。
- ポップアップ（機能の解放・スタンプ・週の目標）は重ならないよう順番に出る（`queuePop`）。
- **続けた日数と休み券**（`streakNow`・`streakDay`）：あそんだ日が続くと「続けて n日」。週の目標をたっせいすると休み券を1まい（2まいまで）。休んだ日があっても、休み券の数までなら日数は切れない（休み券は使った分へる）。切れたときは責めずに「また今日から始めよう！ 前は n日続いたよ」
- **今週は何日やる？**（`openWeekPlan`）：週の最初に開いたとき、2日・3日・5日から自分で選ぶ。それがその週の目標になる。月が変わった最初の週は「新しい月！」
- **つぎのおすすめ**（`resultRecs`）：クリア画面に、進みぐあいに合わせて1〜3こ出す。いちばん進んでいるステージ（形式・タイトル・「〜できるようになる」）／そのステージにまだ覚えていない新しい単語があれば「単語道場：0-4 の新しい単語 n語」／今日の復習が3文以上なら「にがて復習」／このステージをまだ手練でクリアしていなければ「手練モードで」（1回だけ手練で遊べる。全体のモードは変えない）、手練を済ませてハードが開いていれば「ハードモードで」。おすすめがあるときは「つぎのステージ」ボタンは目立たない色にする
- **クリア画面の自動スクロール**（`resultTour`）：クリア画面の並びは「〜クリア！」→ 星 →「できるようになった！」（ここまでが最初の画面）→ お祝い（ミッション・レアシール・せいちょう・島のごほうびなど。`r-cele`）→「つぎのおすすめ」。画面に入りきらない所まで自動で下がる（最初は「できるようになった！」を読む5秒、そのあと4秒）。右下の輪が残り秒数を出し、ゲージが減っていく。マウスを乗せると✕になり、押すとそのページは自動スクロールなし。自分でスクロール・キーを押したときも止まる。ポップアップが出ている間は待つ。全部が画面に入っているときは何もしない
- **やりたいこと**（`openDream`）：ステージを3つクリアしたら1回だけ「○○語が話せるようになったら、何がしたい？」と聞く（6つの例から選ぶか自分で書く・「あとで」も可）。決めたことはマップの上に小さく1行で出て、タップで変えられる。1日の最初のあいさつで「「○○」に向けて、今日も1歩！」、初めてクリアしたステージの結果に、ときどき「「○○」に1歩近づいた！」
- **ドイツ語の打ちこみ**：ä・ö・ü・ß のないキーボード向けに、打ちこみのステージ（LV3・LV4・ボス）の箱の下に ä ö ü ß のボタンを出す（押すと、いま打っている箱のカーソルの位置に入る。`umlautBar`・`typeUmlaut`）。ae・oe・ue・ss で打っても正解（もとから）。文字数ヒントの ●○ も、ae などを1文字として数える
- **ホーム画面に追加**：公開版（`preview/`）は manifest とアイコン（`icon-192.png`・`icon-512.png`・`apple-touch-icon.png`）つき。スマホの「≡」メニューに「ホーム画面に追加」（Android は追加のダイアログ、iPhone は Safari の共有ボタンからの手順を表示）

## ★のごほうび

- 画面上部に「★ あつめた数 / 全部（234）」と称号を出す（`renderStarPill`）。タップで「コレクション」へ
- 称号（`TITLES`、全★に対する割合）：語順のたまご → ひよこ（5%）→ みならい（15%）→ 箱ならべ名人（30%）→ 語順ハンター（50%）→ 語順はかせ（70%）→ 語順の達人（90%）→ ゴジュンマスター（全部）
- 島がそだつ（ワールドごとの★、18こ中）：6こで道ばたに花、12こでステージに旗、18こ全部でにじと花火（動きを減らす設定では花火を出さない）。何こで何が起きるかは**ないしょ**。ワールド名の横には集めた★の数だけを出す（`renderGrow`・`worldTier`・`growFlowers`）
- 18こ全部集めると、そのワールドの衣装（`COSTUMES`、13種類）がもらえる。「コレクション」の「ハコまるの衣装」でタップして着がえ（`save.outfit`）。頭の衣装はぼうし・王冠の代わりにかぶる
- 同じく18こで、そのワールドの「おまけステージ」（5問・LV3）が開く。ワールド名の横の★の数が、18こで「★18 おまけステージ」のボタンに変わる（まだクリアしていない間はゆっくり光る）
- 結果画面で、花・旗・にじ・衣装・おまけ・称号アップをお知らせ（`starRewards`）。次に何が起きるかは書かず「また何か起きるかも…？」とだけ言う。衣装は「着せる」ですぐ着られる
- おまけステージの★はワールドの★には数えない

### おまけステージの書き方

CSV の stage を **90 以上**（いまは 99）にすると、そのワールドのおまけステージになる（ステージ一覧・マップの道には入らない）。英語は `data/zz-bonus.csv`、ドイツ語は `data-de/zz-bonus.csv`。行の書き方はふつうのステージと同じ（INTRO・GOAL・TALK・Q）。

## 読み上げの声

端末にその言語の声がないときは、日本語の声で読んでしまうのを防ぐため読み上げず、「声がないので Edge か Chrome で開くか、Windows の［設定］→［時刻と言語］→［音声］で追加してね」とお知らせする（`noVoiceNotice`）。声の一覧が遅れて届くブラウザでは、届くまで少し待ってから読む。

## 画面の色

設定の「画面の色」で おまかせ（端末の明るい・暗いに合わせる）／明るい／暗い を選べる（`applyTheme`）。学校の端末で OS の設定を変えられないときに使う。

- コンマは自動：weil などのかたまりの前後、zu ＋ 動詞のかたまりの前、関係文（der Mann, der …, ist …）の前後
- 画面の言葉は `lang/de.js`（置きかえ表）。ゲームのしくみは `LANG` で切りかえ：
  - 「いつ」の M（`M~`）や weil のかたまりを文頭に出すと、自動で 動詞 → 主語 の順になる（V2）
  - ä・ö・ü・ß は ae・oe・ue・ss でも正解。動詞の語尾や冠詞（den / dem など）のちがいはスペルミス扱いにしない
  - 読み上げはドイツ語の声、記録は英語版と別に保存
  - ポイントの自動説明は英語版だけ（ドイツ語版は note に全部書く）

## 日本語の改行

説明文（場面・めあて・できるようになる・レベルの説明・学校のルールなど）は `jaWrap` で、まず文の終わり（。！？）、次に「、」で改行する。それでも入らないときは文節で改行する（`word-break: auto-phrase`、Chrome・Edge のみ。Safari では文字の途中で折り返す）。

## マップの見た目

- 手練モードのときは、どのワールドのマップも「地底」になる：海はマグマ、空・陸・森は暗い岩の色、雲は煙、火の粉が舞う（`applyUnder`、`#mapbox.under` の色の上書き）。空が背景のワールドにも下にマグマの帯が出る。動きを減らす設定のときは火の粉なし

`src/gojun-src.html` の `THEMES` にワールドごとの背景・島の形・道・飾りがある。
